# 🐾 Huellas del Sur

**Conectamos huellas con hogares.**

Plataforma web para facilitar la adopción responsable de animales, conectando refugios de Bahía Blanca con personas interesadas en adoptar.

## Proyecto

Trabajo Final Integrador — Grupo 13.

**Integrantes:**
- Valentina Vitale Haag
- Alesio Fabián Cragno

## Tecnologías

- React
- TypeScript
- Vite
- React Router
- Node.js y Express (backend independiente)

## Requisitos

- Node.js
- npm

## Instalación

Clonar el repositorio e instalar las dependencias:

```bash
npm install
```

## Ejecución local

```bash
npm run dev
```

## Compilación

```bash
npm run build
```

## Vista previa de producción

```bash
npm run preview
```

## Variables de entorno

Crear un archivo `.env` tomando como referencia `.env.example`.

```env
VITE_API_URL=http://localhost:3000/api
```

## Estructura del proyecto

```text
src/
├── components/
├── hooks/
├── pages/
├── services/
├── types/
├── App.tsx
└── main.tsx
```

**Prototipo V1 en desarrollo.**
